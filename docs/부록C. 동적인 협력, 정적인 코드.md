#### 객체는 동적이고 프로그램은 동적이다 → 객체는 시간에 따라 다른 객체와 협력하면서 변화

- 동적 모델은 객체와 협력으로 구성
- 정적 모델은 타입과 관계로 구성

⇒ 정적 모델은 동적 모델의 의해 주도돼야 하고 동적 모델이라는 토대 위에 세워져야 한다.

객체의 정적 모델은 동적 모델이라는 토대 없이 완전해질 수 없음

#### 도메인 - 사용자가 프로그램을 사용하는 대상영역을 가리킴

- 도메인 모델을 작성하는 것이 목표가 아니라 출발점임
- 우리가 도메인에 대한 지식을 표현하고 코드의 구조에 대한 힌트를 제공한다면 어떤 형태든 상관없음
- 우리에게 중요한 것은 소프트웨어의 기능과 객체의 책임

#### 611P 예 Breed → 객체의 타입을 별도의 객체를 이용해 타입을 구현 ⇒ Type Object

코드와 모델의 차이를 줄이기 위해서는 도메인과 코드 간의 차이가 적어야함

도메인의 개념적인 분류 체계가 아니라 객체의 행동과 변경에 영향을 받는다.
