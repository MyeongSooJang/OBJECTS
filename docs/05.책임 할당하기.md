#### 응집도가 낮아지는 경우

- 서로 다른 이유로 변경되는 두 개의 메서드를 가지는 경우 → 책 150P DiscountCondition

#### ⇒ 높이기 위해서는 속성 그룹과 해당 그룹에 접근하는 메서드 그룹을 기준으로 코드를 분리

#### 응집도 판단

- 클래스가 하나의 이상의 이유로 변경시 응집도 낮음
- 클래스의 인스턴스를 초기화하는 시점에  경우에 따라 다른 속성들을 초기화하면 응집도 낮음
- 메서드 그룹이 속성 그룹을 사용하느지 여부로 나뉜다면 응집도가 낮음

#### 코드를 통해 변경의 이유를 파악하는 방법

- 인스턴스 변수가 초기화되는 시점
- 메서드들이 인스턴스 변수를 사용하는 방식
