#### 객체지향 패러다임의 관점 → 객체들의 공동체를 창조

- 역할 : 협력 안에서 수행하는 책임들이 모여 객체가 수행
- 책임 : 협력에 참여하기 위해 수행하는 로직
- 협력 : 기능을 구현하기 위해 수행하는 상호작용

#### 어플리케이션에서 객체가 필요하다 → 그 객체가 어떤 협력에 참요하고 있기 때문

- 객체의 행동을 결정하는 것은 객체가 참여하고 있는 협력

#### 객체는 자신이 맡은 책임을 수행하는데 필요한 정보를 알고 있을 책임이 존재

#### 객체지향 설계는 협력에 필요한 메시지를 찾고 메시지에 적절한 객체를 선택하는 반복적인 과정을 통해 이뤄짐

#### 초보자들이 하는 실수

- 객체에 필요한 상태가 무엇인지를 결정 → 상태에 필요한 행동을 결정

#### 내부 구현이 객체의 퍼블릭 인터페이스에 노출되도록 만듬 → 캡슐화를 저해

#### 협력이라는 문맥 안에서 역할은 특정한 협력에 참여해서 책임을 수행하는 객체의 일부
