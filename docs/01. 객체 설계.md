#### 소프트웨어 모듈 3가지 목적

1. 실행 중 제대로 동작
2. 변경을 위해 존재하는 것 → 간단한 작업으로 변경이 가능해야 함
3. 코드를 읽는 사람과 의사소통하는 것

#### 의존성은 변경에 대한 영향을 암시

#### 캡슐화 목적 → 변경하기 쉬운 객체를 만듬

#### 절차적 프로그래밍 - 프로세스가 필요한 모든 데이터에 의존 ⇒ 변경에 취약

#### 객체 지향 설계 - 각 객체에 책임이 적절하게 분배

⇒ 객체 지향 어플리케이션은 스스로 책임을 수행하는 자율적인 객체들의 공동체

#### 현실에서는 수동적인 존재라도 객체지향의 세계에 들어오면 모든 것이 능동적

⇒ 모든 객체들이 자율적으로 행동으로 하는 설계
